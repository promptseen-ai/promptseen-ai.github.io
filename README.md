# PromptSeen AI

A lightweight, responsive inspiration library for AI photo prompts, video concepts and editing templates.

## Website sections
- Hero introduction and discovery navigation
- Category shortcuts: Portrait, Couple, Street, Cinematic, Seasonal, AI Video
- Featured creative ideas
- Searchable prompt cards and category filtering
- One-click copy-to-clipboard for prompt text
- Show-more cards
- AI video inspiration section
- Editing template ideas
- Responsive mobile navigation

## Stack
Static HTML, CSS and vanilla JavaScript. No build step or framework required.

## Deploy
GitHub Pages can publish this repository from the main branch root. The entry point is `index.html`.

## Content and identity
This is an independent project. It does not use any competitor owner/person identity, personal bio, About section, or copied article text/images. The page structure is inspired by common prompt-gallery website patterns; all starter prompt text is original.
